# CV Website Placeholder Assets

Drop replacement images into these folders and update `cv-website/index.html` when you are ready to swap placeholders for real media.

- `hero/`: exterior building hero or main apartment photography
- `gallery/interior/`: living room, kitchen, bedroom, bathroom, closet images
- `gallery/exterior/`: exterior building, signage, walkways, mountain views
- `gallery/amenities/`: pool, clubhouse, courtyard, playground, pet wash, fitness
- `amenities/pool/`
- `amenities/fitness/`
- `amenities/clubhouse/`
- `floorplans/`: floor plan diagrams
- `neighborhood/`: shopping, dining, entertainment, trail/location images
- `pet-friendly/`: pet and pet-spa lifestyle media
- `logo/`: logo or wordmark files
